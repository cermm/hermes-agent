# Triage labels

Retain existing category labels: `bug`, `enhancement`, `documentation`, `question` and other established repository labels. Map canonical triage state roles as follows.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer classification required |
| needs-info | needs-info | More evidence or information required |
| ready-for-agent | ready-for-agent | Fully specified autonomous implementation |
| ready-for-human | ready-for-human | Human implementation required |
| wontfix | wontfix | Work will not be actioned |

Preserve current label metadata and valid readiness. Use the triage procedure's required AI-generated disclosure in agent briefs. Do not mix these state labels into Wayfinder decision maps/tickets. A routine delegated technical confirmation does not turn a non-overridable platform or human capability requirement into an autonomous action.
